## Локальный запуск (для соавторов)

**Требования:** Docker, Rust, Node.js

```bash
# 1. Поднять PostgreSQL
docker compose up -d

# 2. Скопировать конфиг окружения
cp backend/.env.example backend/.env

# 3. Применить миграции (sqlx-cli нужен один раз: cargo install sqlx-cli --no-default-features --features postgres)
cd backend && sqlx migrate run

# 4. Запустить бэкенд
cargo run

# 5. Запустить фронтенд (в другом терминале)
cd frontend && npm install && npm run dev
```

> `.env` в git не попадает — у каждого свой локальный файл. Менять ничего не нужно, всё уже настроено под локальный Docker.

## Система анализа загрузки пунктов выдачи (ПВЗ)
### Описание проекта
Проект моделирует работу пунктов выдачи заказов (ПВЗ) маркетплейса.  
Система фиксирует операции, происходящие в ПВЗ (приём, выдача, возврат), и рассчитывает загрузку пунктов выдачи по часам.

Основная задача системы — определить, насколько загружен каждый ПВЗ и выявить моменты перегрузки, когда количество операций превышает допустимую пропускную способность.

Это позволяет анализировать работу ПВЗ и выявлять часы пик, в которые требуется перераспределение нагрузки или изменение расписания.

---
## Основная логика системы
В системе фиксируются три типа операций:

- **in** — приём товаров в ПВЗ
- **out** — выдача заказов клиентам
- **return** — возврат товаров
Каждый ПВЗ имеет:

- адрес
- регион
- пропускную способность (**capacity_per_hour**) — максимальное количество операций в час
- расписание работы по дням недели
    

Каждая операция содержит:

- ПВЗ
- тип операции
- временную метку выполнения

---

## Расчёт загрузки ПВЗ
Загрузка рассчитывается по формуле:

```
load = ops_per_hour / capacity_per_hour
```

где:

- **ops_per_hour** — количество операций в конкретный час
- **capacity_per_hour** — максимальная пропускная способность ПВЗ
    

Если:

```
load > 1.0
```

это означает **перегрузку ПВЗ**.

---

## Отчёт «Загрузка ПВЗ»
Система формирует отчёт, который показывает загрузку пунктов выдачи по часам.

В отчёте отображаются:

- pvz_id
    
- дата
- час
- количество операций
- пропускная способность
- процент загрузки
- флаг перегрузки

---
## Фильтры отчёта
Пользователь может фильтровать отчёт по:

- периоду (дата / диапазон дат)
- ПВЗ
- региону    
- типу операции

---

## Экспорт данных
Отчёт можно экспортировать в CSV.

Формат:

```
pvz_id, date, hour, ops, capacity, load
```

Это позволяет использовать данные во внешних аналитических системах.

---

## Валидация данных
Система проверяет корректность всех операций.

Основные проверки:

1. Операция должна относиться к существующему ПВЗ.
    
2. Тип операции может быть только:
    
    - `in`
    - `out`
    - `return`
        
3. Операция должна происходить **в часы работы ПВЗ**.
    
4. Расписание должно иметь корректные значения:
    
    - `open_time < close_time`
    - `weekday ∈ 0..6`
        
5. Если в день нет расписания — операции запрещены.
    

Все ошибки данных логируются.

## Архитектура проекта
Проект состоит из двух частей.

### Backend

- Rust
- Actix Web
- PostgreSQL
- SQLx
    

Backend отвечает за:

- хранение данных
- обработку операций
- расчёт загрузки
- формирование отчётов
- экспорт CSV

### Frontend

- React
- TypeScript
- Vite
- SCSS
    

Frontend предоставляет веб-интерфейс для:

- просмотра ПВЗ
- фильтрации отчётов
- анализа загрузки
- визуализации данных

---

## Структура базы данных
### pvz
Информация о пунктах выдачи.

```
pvz  
- pvz_id  
- address  
- region  
- capacity_per_hour
```

### schedule
Расписание работы ПВЗ.

```
schedule  
- pvz_id  
- weekday  
- open_time  
- close_time
```

### operations
Операции, выполняемые в ПВЗ.

```
operations  
- op_id  
- pvz_id  
- ts  
- type
```

---

## Генерация тестовых данных
В проекте используется синтетический набор данных.

Генерируется:

- несколько ПВЗ
- расписание работы
- не менее **200 операций**
    

Это позволяет моделировать загрузку ПВЗ и тестировать отчёты.

---

## Основные показатели (KPI)

Система позволяет рассчитывать:

- **среднюю загрузку ПВЗ в часы пик**
- **долю интервалов с перегрузкой (load > 100%)**
    

Эти показатели используются для оценки эффективности работы пунктов выдачи.

---

## Демонстрационный сценарий

- Пользователь открывает веб-интерфейс системы.
- Выбирает период анализа.
- Система строит отчёт загрузки ПВЗ    
- Пользователь может:
    
    - отфильтровать данные
    - посмотреть перегруженные часы
    - экспортировать отчёт в CSV.
