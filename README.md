# Что это за репозиторий?
**ПВЗ Master — это информационно-аналитическая система для оптимизации работы пунктов выдачи заказов.**
Проект решает проблему «слепых зон» в управлении нагрузкой персонала, преобразуя данные об операциях (приемка, выдача, возврат) в наглядную аналитику.

# О чем проект?
Ключевая идея системы — автоматический расчет загрузки ПВЗ в режиме реального времени.

Формула расчета:
**load = ops_per_hour / capacity_per_hour**

**Где:**

**ops_per_hour** — сумма операций (**in** + **out** + **return**) за астрономический час.

**capacity_per_hour** — паспортная пропускная способность точки.

**Overload** — состояние, когда **load > 1.0** (подсвечивается в интерфейсе красным).

# Команда проекта
**Team Lead** — контроль RBAC, защита роутов, общая архитектура.

**Backend** — Rust (Actix Web), SQLx, расчетная логика, экспорт в CSV.

**Frontend** (Business) — React, таблицы с почасовой детализацией, фильтрация.

**Frontend** (Visual) — Дизайн-система (SCSS), графики загрузки.

# Что уже реализовано в MVP?
На текущий момент система поддерживает:

**Учет НСИ:** Справочник ПВЗ и графиков работы.

**Журнал операций:** Регистрация транзакций типов in, out, return.

**Smart Analytics:** Автоматическая детекция статусов перегрузки.

**Reporting Unit:** Формирование отчетов с фильтрами по региону, дате и типу операции.

**Data Portability:** Экспорт сформированных аналитических срезов в формат CSV.
