# П16. Добавление расширений

## План расширений проекта (Project Extensions)

### 1. Функциональные расширения (Бизнес-логика)
Эти модули расширяют возможности оператора и владельца, превращая систему мониторинга в полноценную ERP-систему для ПВЗ.

- [ ] **Модуль «Инвентаризация»:** Проведение плановых проверок остатков на складе. `InventoryAuditStarted` → `DiscrepancyDetected` (выявление расхождений).
- [ ] **Интеллектуальное прогнозирование:** Предсказание нагрузки на следующую неделю на основе исторических данных.

### 2. Технические расширения (Архитектура)
Улучшения, которые делают систему более стабильной и готовой к высоким нагрузкам.

- [ ] **Кеширование данных (Redis):** Хранение текущих счетчиков `ops_per_hour` в оперативной памяти для мгновенного доступа без обращения к PostgreSQL.
- [ ] **Объектное хранилище (S3/MinIO):** Хранение фотофиксации поврежденных посылок при приемке (событие `ItemDamaged`).
- [ ] **WebSockets:** Переход от классических HTTP-запросов к Real-time обновлению дашбордов. Владелец увидит статус «Перегрузка» мгновенно, без перезагрузки страницы.

### 3. Расширение интеграций (External APIs)
-[x] **API Маркетплейсов:** Автоматическая подгрузка данных о прибывающих машинах из Wildberries/Ozon/Яндекс Маркет.
-[ ] **Гео-сервисы:** Отображение ПВЗ на интерактивной карте с тепловыми зонами нагрузки (Heatmaps).
