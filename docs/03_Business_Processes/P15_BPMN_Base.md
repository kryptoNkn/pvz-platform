# П15. Моделирование базовой схемы (BPMN)

### 1. Участники процесса (Lanes)
* **Клиент / Курьер:** Инициаторы внешних событий (привоз или получение).
* **Оператор ПВЗ:** Исполнитель, работающий в интерфейсе React.
* **Система (Backend):** Сервис на Rust, обрабатывающий бизнес-логику и политики.

### 2. Описание процесса «Приемка и Сортировка»
1.  **Начальное событие:** Прибытие курьера с партией заказов.
2.  **Действие (Оператор):** Сканирование штрих-кода посылки.
3.  **Задача (Система):** Регистрация события `ItemReceived`.
4.  **Развилка (Gateway):** Проверка данных посылки.
    * *Ошибка:* Переход к задаче «Корректировка данных».
    * *Успех:* Переход к задаче «Определение зоны хранения».
5.  **Действие (Оператор):** Физическое размещение посылки на полке.

### 3. Описание процесса «Выдача и Расчет нагрузки»
1.  **Начальное событие:** Визит клиента.
2.  **Задача (Оператор):** Поиск заказа в системе по ID.
3.  **Подпроцесс (Система):** Выполнение команды `IssueCommand`.
    * **Событие:** `ItemIssued` (Выдано).
    * **Параллельная ветка:** Запуск политики `OverloadPolicy`.
4.  **Развилка (Gateway):** Превышен ли лимит `ops_per_hour`?
    * *Да:* Система генерирует событие **OverloadDetected** → Обновление UI (красная подсветка).
    * *Нет:* Система обновляет счетчик в обычном режиме.
5.  **Конечное событие:** Посылка передана, данные синхронизированы.
