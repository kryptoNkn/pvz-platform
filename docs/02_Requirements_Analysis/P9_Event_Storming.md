# П9. Формализация требований через Event Storming

## 1. Слой «Доступ и Управление» (IAM)
| Команда (Command) | Событие (Event) | Актор (Actor) |
| :--- | :--- | :--- |
| Регистрация в системе | **UserRegistered** | Посетитель |
| Ввод логина и пароля | **UserAuthenticated** | Все роли |
| Валидация прав доступа | **AccessGranted / AccessDenied** | Middleware |
| Удаление своего профиля | **AccountDeleted** | Все роли |

## 2. Слой «Операции с посылками» (Operational)
| Команда (Command) | Событие (Event) | Актор (Actor) |
| :--- | :--- | :--- |
| Зафиксировать приемку | **ItemReceived** (in) | Оператор |
| Подтвердить выдачу | **ItemIssued** (out) | Оператор |
| Оформить возврат | **ItemReturned** (return) | Оператор |
| Поиск по ID посылки | **SearchPerformed** | Оператор |

## 3. Слой «Бизнес-логика и Аналитика» (Analytics)
| Команда (Command) | Событие (Event) | Актор (Actor) |
| :--- | :--- | :--- |
| Создание нового ПВЗ | **PvzCreated** | Владелец |
| Настройка лимитов | **CapacitySet** | Владелец |
| Расчет нагрузки (%) | **LoadCalculated** | Система (Backend) |
| Формирование отчета | **ReportGenerated** | Владелец |
| Выгрузка в файл | **DataExported** (CSV) | Владелец |

## 4. Политики и Реакции (Policies)
1.  **Overload Policy:** * *Event:* `LoadCalculated` (если > 100%).
    * *Reaction:* Система генерирует событие **StatusChangedToOverload** → UI подсвечивает ПВЗ красным цветом.
2.  **Audit Policy:**
    * *Event:* Любая техническая ошибка (Exception).
    * *Reaction:* Запись события в **ErrorLogStored** → Администратор видит уведомление в журнале ошибок.
3.  **Security Policy:**
    * *Event:* `UserAuthenticated`.
    * *Reaction:* Генерация **JWTTokenIssued** → Клиент получает доступ к защищенным роутам.

## 5. Агрегаты (Boundaries)
* **Агрегат ПВЗ:** Объединяет события создания, настройки графиков и лимитов.
* **Агрегат Транзакций:** Объединяет логи приемки, выдачи и возвратов.
* **Агрегат Пользователя:** Управляет сессиями и правами доступа.
