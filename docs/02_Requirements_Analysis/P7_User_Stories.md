# П7. Формализация требований через User Stories

### 1. Команды и Управление доступом (Identity & Access)
- **Как** пользователь, **я хочу** пройти аутентификацию через JWT, **чтобы** безопасно работать со своими данными без необходимости постоянного ввода пароля.
- **Как** администратор, **я хочу** управлять правами доступа через роли (RBAC), **чтобы** ограничить доступ операторов к стратегической аналитике владельца.
- **Как** пользователь, **я хочу** видеть индикацию активной сессии, **чтобы** контролировать безопасность своего аккаунта.

### 2. Операционная деятельность и События (Operations)
- **Как** оператор, **я хочу** фиксировать события «Приемка», «Выдача» и «Возврат», **чтобы** система автоматически обновляла лог операций.
- **Как** оператор, **я хочу** использовать быстрый поиск по ID посылки или клиенту, **чтобы** сократить время обслуживания в очереди.
- **Как** оператор, **я хочу** получать мгновенную обратную связь от системы при вводе данных, **чтобы** избежать ошибок в журнале транзакций.

### 3. Аналитика и Политики (Analytics & Policies)
- **Как** владелец, **я хочу**, чтобы система автоматически применяла «Политику детекции перегрузки», **чтобы** я мог видеть реальный статус ПВЗ без ручных расчетов.
- **Как** владелец, **я хочу** видеть визуальную подсветку (красный цвет) для перегруженных точек, **чтобы** мгновенно фокусироваться на проблемных зонах сети.
- **Как** аналитик, **я хочу** применять фильтры по датам и типам операций, **чтобы** изучать динамику нагрузки в «часы пик».

### 4. Интерфейс и Навигация (UI/UX)
- **Как** пользователь, **я хочу** использовать единую навигационную панель, **чтобы** быстро переключаться между дашбордом, списком ПВЗ и журналом ошибок.
- **Как** пользователь, **я хочу**, чтобы все формы (добавление ПВЗ, редактирование) открывались в модальных окнах, **чтобы** не терять контекст текущей страницы.
- **Как** пользователь, **я хочу** получать уведомления об успешном выполнении команд (сохранение, экспорт), **чтобы** быть уверенным в работе системы.

### 5. Инфраструктура и Экспорт (Infrastructure)
- **Как** владелец, **я хочу** инициировать команду экспорта данных в CSV, **чтобы** передать отчетность в другие отделы.
- **Как** разработчик, **я хочу**, чтобы каждый пуш в GitVerse автоматически запускал тесты, **чтобы** гарантировать стабильность работы всех политик и агрегатов.
