# П9–П11. Event Storming & DDD

**Домены:**
- Домен Склада
- Домен Аналитики
- Домен Пользователей

**События (пример):**
- Заказ принят
- Заказ выдан
- Сформирован отчет

**Команды:**
- «Принять заказ»
- «Выдать заказ»
- «Сформировать отчет»

**Политики/реакции (пример):**
- При приемке заказа обновляется нагрузка ПВЗ.
- При выдаче заказа уменьшается текущая очередь.
