# П12. Моделирование внешних сервисов, агрегатов и контекстов

## 1. Ограниченные контексты (Bounded Contexts)
Система разделена на изолированные области ответственности, что позволяет четко разграничить логику:

- **Identity & Access Context (IAM)**: Управление пользователями, их ролями (Владелец, Админ, Оператор) и сессиями на базе JWT.
- **Operational Context**: Регистрация первичных событий (приемка, выдача, возврат) и ведение логов операций.
- **Analytics Context**: Высокоуровневая логика — расчет `ops_per_hour`, детекция перегрузок и агрегация данных для дашбордов.
- **Inventory/NSI Context**: Управление справочниками (реестр ПВЗ, графики работы, адреса).

## 2. Агрегаты (Aggregates)
Агрегаты определяют границы согласованности данных:

### Агрегат: ПВЗ (Point of Presence)
- **Root Entity**: `Pvz`
- **Value Objects**: `Schedule` (Расписание), `Location` (Адрес).
- **Описание**: Управляет жизненным циклом точки выдачи и её характеристиками.

### Агрегат: Операция (Operation)
- **Root Entity**: `Operation`
- **Value Objects**: `TransactionType` (in/out/return), `Timeline`.
- **Описание**: Одиночное событие в системе, неизменяемое после создания.

### Агрегат: Аналитический Срез (Metric Snapshot)
- **Root Entity**: `PvzLoadMetric`
- **Value Objects**: `LoadFactor` (%), `Status` (Normal/Overload).
- **Описание**: Результат работы расчетного модуля, связывающий данные операций и лимиты ПВЗ.

## 3. Внешние сервисы и Инфраструктура
Моделирование взаимодействия с компонентами вне основной бизнес-логики:

- **Database Service (PostgreSQL)**: Реляционное хранилище, обеспечивающее ACID-свойства транзакций.
- **Auth Provider (JWT Stateless)**: Механизм проверки подлинности, вынесенный в слой Middleware (Actix Web).
- **Reporting Engine**: Сервис формирования CSV-отчетов для экспорта данных во внешние системы.
- **GitVerse Infrastructure**: Российская экосистема для хранения кода (Git) и выполнения пайплайнов (Actions).

## 4. Карта контекстных связей (Context Mapping)
- **IAM -> All Contexts**: (Upstream-Downstream). Контекст авторизации передает идентификатор и роль пользователя, ограничивая доступ к данным.
- **Inventory -> Analytics**: (Customer-Supplier). Контекст ПВЗ предоставляет данные о лимитах и графиках для расчета метрик.
- **Operational -> Analytics**: (Published Language). Поток событий об операциях является входящим сигналом для модуля детекции перегрузок.
