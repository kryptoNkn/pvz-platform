# П6. Формализация требований через User Stories

## 1. Контекст: Авторизация и Управление профилем
- **Как** пользователь системы, **я хочу** иметь возможность зарегистрироваться и войти в аккаунт, **чтобы** получить доступ к функциям согласно моей роли.
- **Как** пользователь, **я хочу** видеть свои личные данные в профиле, **чтобы** убедиться в корректности привязки к системе.
- **Как** пользователь, **я хочу** иметь возможность самостоятельно удалить аккаунт, **чтобы** соблюсти свои права на конфиденциальность данных.

## 2. Контекст: Операционная деятельность (Оператор)
- **Как** оператор ПВЗ, **я хочу** регистрировать приемку, выдачу и возврат товаров, **чтобы** система могла учитывать нагрузку на точку в реальном времени.
- **Как** оператор, **я хочу** видеть статус загруженности моего ПВЗ (цветовой индикатор), **чтобы** понимать, когда интенсивность работы становится критической.
- **Как** оператор, **я хочу** искать конкретные операции в логе, **чтобы** оперативно решать вопросы клиентов по движению их посылок.

## 3. Контекст: Стратегическое управление (Владелец)
- **Как** владелец сети, **я хочу** видеть сводный дашборд со средней загрузкой по всем ПВЗ, **чтобы** оценивать общую эффективность бизнеса за месяц.
- **Как** владелец, **я хочу** добавлять новые ПВЗ и настраивать их пропускную способность (оп/час), **чтобы** система корректно рассчитывала перегрузки.
- **Как** владелец, **я хочу** настраивать графики работы для каждого пункта, **чтобы** аналитика учитывала только рабочие часы сотрудников.
- **Как** владелец, **я хочу** экспортировать отчеты в формате CSV, **чтобы** проводить дополнительный анализ данных в сторонних инструментах.

## 4. Контекст: Технический аудит (Администратор)
- **Как** администратор, **я хочу** иметь доступ к «Журналу ошибок», **чтобы** оперативно выявлять сбои в расчетах или невалидные данные.
- **Как** администратор, **я хочу** управлять ролями пользователей (RBAC), **чтобы** гарантировать безопасность и разграничение прав доступа к эндпоинтам.

## 5. Контекст: Аналитический модуль (Системная логика)
- **Как** система, **я должна** автоматически рассчитывать `load %` при каждой новой операции, **чтобы** предоставлять актуальную информацию пользователям.
- **Как** система, **я должна** блокировать несанкционированные запросы к административным функциям, **чтобы** защитить данные владельца от операторов.
