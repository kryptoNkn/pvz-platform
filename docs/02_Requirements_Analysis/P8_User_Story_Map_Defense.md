# П8. Защита представления проекта в виде User Story Map

**Вход и Управление профилем**
- Пройти авторизацию
- Настроить профиль

**Обзор сети и Мониторинг**
- Просмотреть дашборд
- Увидеть перегруженные точки
- Предоставить список ПВЗ

**Операционные Действия**
- Зарегистрировать операцию (Приемка, Выдача)
- Обработать возврат

**Техническое обслуживание**

**Релиз №1 (MVP)**
- Создать учетную запись
- Авторизоваться с ролью
- Увидеть общий статус сети (158 ПВЗ)
- Увидеть % загрузки ПВЗ
- Просмотреть справочник ПВЗ
- Записать операцию: Приемка
- Записать операцию: Выдача
- Назначить роль пользователю
- Создать базовые фильтры

**Релиз №2 (Should Have)**
- Подключить электронную подпись
- Увидеть подсвеченную перегрузку (Критический индикатор)
- Просмотреть сложную таблицу (Отчет "Загрузка")
- Применить почасовую детализацию
- Экспортировать отчет в CSV
- Проверить валидацию данных

**Релиз №3 (Could Have)**
- Просмотреть Heatmap загрузки
- Сравнить эффективность разных ПВЗ
- Выполнить пакетный импорт операций
- Анализировать Heatmaps в таблицах
- Проверить поисковые алгоритмы

**Won't Have (Не входит в MVP)**
- Использовать интерактивные геокарты
- Интеграция с ERP/WMS
- Прогнозная аналитика ML
- Разработать мобильный клиент
- Сложная BI-визуализация
