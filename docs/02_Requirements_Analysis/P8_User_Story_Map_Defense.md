# П8. Защита представления проекта в виде User Story Map

**Путь посылки:** Приемка → Сортировка → Хранение → Выдача.

**Ключевые активности:**
- Приемка: регистрация заказа, проверка статуса.
- Сортировка: распределение по зонам хранения.
- Хранение: контроль сроков и статусов.
- Выдача: идентификация клиента и фиксация операции.
