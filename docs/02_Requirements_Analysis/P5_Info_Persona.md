# П5. Ознакомление с поиском информации и персоной

**Персона:** Менеджер ПВЗ (управляет сменами и качеством обслуживания).  
**Цели:** равномерная загрузка, минимизация очередей, контроль SLA.  
**Проблемы:** отсутствие прогнозов нагрузки, ручное планирование.

**Источники информации:**
- Внутренние отчеты ПВЗ (нагрузка по часам).
- Обратная связь операторов и менеджеров.
- Логи операций выдачи/приемки.


**Персона:** Оператор ПВЗ (управляет загрузкой и отслеживает состояние определенного ПВЗ).  
**Цели:** упрощение системы товаров, отслеживания статуса и состояния пвз. 
**Проблемы:** нет возможности просматривать конкретные товары, ручное добавление операций.

**Источники информации:**
- Внутренние отчет ПВЗ (нагрузка конркретного пвз).
- Обратная связь операторов и менеджеров.
- Логи операций выдачи/приемки.
