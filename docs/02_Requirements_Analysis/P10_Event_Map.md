# П10. Построение карты событий

### 1. События жизненного цикла пользователя
- **UserRegistrationEvent**: Регистрация пользователя (ФИО, телефон, пароль) → Создание записи в БД.
- **UserLoginEvent**: Аутентификация пользователя → Генерация JWT-токена и определение роли (RBAC).
- **SessionInitializationEvent**: Инициализация сессии на Frontend → Проверка прав доступа через Route Guards.
- **ProfileUpdateEvent**: Просмотр или изменение данных профиля.
- **AccountDeletionEvent**: Удаление аккаунта пользователем.

### 2. Операционные события (Уровень ПВЗ)
- **ItemReceptionEvent (in)**: Регистрация приемки посылки → Запись в лог операций (`Operations`).
- **ItemIssueEvent (out)**: Регистрация выдачи посылки клиенту → Обновление лога операций.
- **ItemReturnEvent (return)**: Оформление возврата товара → Запись в лог операций.
- **OverloadDetectedEvent**: Автоматическое событие системы при превышении порога `ops_per_hour` → Изменение статуса на «Перегрузка» (подсветка красным).

### 3. Аналитические и управленческие события
- **DashboardRefreshEvent**: Агрегация данных по всей сети (всего ПВЗ, средняя загрузка %) → Отображение KPI владельцу.
- **PvzCreationEvent**: Добавление нового ПВЗ (адрес, пропускная способность, график) → Запись в справочник НСИ.
- **ScheduleUpdateEvent**: Изменение графика работы ПВЗ → Пересчет доступного времени для аналитики.
- **ReportGenerationEvent**: Запрос на формирование отчета «Загрузка ПВЗ» с фильтрами.
- **DataExportEvent**: Выгрузка данных в формате CSV.

### 4. Системные и технические события
- **SystemErrorLogEvent**: Регистрация ошибки в «Журнале ошибок» (невалидные данные, сбои расчетов).
- **ApiRequestInterceptEvent**: Перехват запроса в Actix Middleware для проверки валидности токена.
- **DatabaseMigrationEvent**: Выполнение SQL-миграций при обновлении схемы БД.
- **CiCdPipelineTrigger**: Пуш кода в GitVerse → Запуск сборки, тестов (cargo test) и линтинга.
