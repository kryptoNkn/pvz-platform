# П12. Контексты и глоссарий

**Контексты:**
- Контекст склада (операции, статусы заказов)
- Контекст аналитики (нагрузка, метрики)
- Контекст пользователей (роли, доступ)

**Термины:**
- **Пропускная способность** — максимум заказов за единицу времени.
- **Коэффициент нагрузки** — отношение фактического потока к пропускной способности.
