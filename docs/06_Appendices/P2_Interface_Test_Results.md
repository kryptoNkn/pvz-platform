# П2. Результаты тестирования интерфейса

## 1. Методика проверки

Проверка выполнена по текущей реализации frontend-приложения.

- Производственная сборка: `npm run build`
- Проверка качества кода: `npm run lint`
- Дополнительно: анализ реализованных пользовательских сценариев по коду интерфейса

Автоматические UI-тесты в репозитории не найдены, поэтому функциональные результаты ниже зафиксированы по текущей реализации экранов и маршрутизации.

## 3. Ключевые замечания

1. Сборка frontend проходит успешно.
2. ESLint сейчас показывает следующие проблемные места:
   - `frontend/src/pages/add-pvz/ui/AddPvzPage.tsx` - `no-explicit-any`
   - `frontend/src/pages/settings/ui/SettingsPage.tsx` - использование `Date.now()` в render
   - `frontend/src/shared/i18n/LangContext.tsx` - `react-refresh/only-export-components`
   - `frontend/src/widgets/notifications-panel/ui/NotificationsPanel.tsx` - `setState` внутри `useEffect`
   - `frontend/src/widgets/sidebar/ui/Sidebar.tsx` - `@ts-ignore`
   - `frontend/src/widgets/topbar/ui/Topbar.tsx` - `setState` внутри `useEffect`
3. Для полноценного UI-автотестирования в проекте пока не хватает отдельного набора e2e/интеграционных тестов.
