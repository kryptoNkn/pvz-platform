# П18. Анализ предметной области

## 1. Сущности и объекты (Domain Entities)
Предметная область состоит из трех ключевых групп объектов:

* **Инфраструктурные объекты:**
    * **ПВЗ (Point of Presence):** Физическая точка со своими характеристиками (адрес, график работы).
    * **Пропускная способность (Capacity):** Ключевой параметр — максимальное количество операций, которое точка может обработать за час без потери качества сервиса.
* **Операционные объекты:**
    * **Заказ (Order/Item):** Единица учета, проходящая через ПВЗ.
    * **Операция (Operation):** Атомарное событие изменения статуса заказа (Приемка, Выдача, Возврат). Каждая операция имеет временную метку (timestamp).
* **Субъекты:**
    * **Персонал (Операторы):** Создают нагрузку на систему, выполняя операции.
    * **Клиенты:** Генерируют спрос на операции (выдачу и возврат).

## 2. Ключевые процессы и их специфика
В данной предметной области критически важна **временная привязка** событий. 

1.  **Неравномерность нагрузки:** Поток клиентов в ПВЗ не линеен (пики утром, вечером и в выходные). Это создает потребность в динамическом расчете коэффициента загрузки.
2.  **Накопительный эффект:** Задержка на этапе «Приемка» (например, из-за большого объема товара) напрямую влияет на скорость «Выдачи» клиентам, создавая очереди.
3.  **Ограничение ресурса:** В отличие от цифровых сервисов, ПВЗ ограничен физическим пространством и количеством сотрудников (окон выдачи).

## 3. Проблематика 
Анализ выявил следующие «боли» бизнеса, которые решает проект:
* **Скрытая перегрузка:** Владелец не видит момента, когда ПВЗ начинает работать «на износ», пока не начнут поступать жалобы на очереди.
* **Отсутствие метрик:** Невозможность объективно сравнить эффективность разных точек сети.
* **Человеческий фактор:** Риск ошибок при ручном ведении журналов операций.

## 4. Глоссарий
Для синхронизации команды разработки и бизнеса используются следующие термины:
* **Load Factor:** Процентное соотношение реальных операций к лимиту ПВЗ.
* **Overload:** Состояние системы, при котором Load Factor превышает 100%.
* **Inbound (Приемка):** Процесс поступления товара в ПВЗ.
* **Outbound (Выдача):** Процесс передачи товара клиенту.

## 5. Концептуальная модель данных (ER-кратко)
Предметная область диктует следующую связь:
* **ПВЗ** владеет многими **Операциями**.
* **Пользователь** (с определенной **Ролью**) инициирует **Операции**.
* **Политика** анализирует поток **Операций** и меняет статус **ПВЗ**.
