# П26. Пример CSV-экспорта операций

## 1. Назначение

Этот файл показывает пример CSV-выгрузки, которую система отдает через endpoint:

- `GET /api/v1/operations/export`

Экспорт используется для передачи операционных данных во внешние инструменты анализа, Excel и BI-системы.

## 2. Формат файла

Файл представляет собой CSV с разделителем `,`.

Порядок колонок фиксированный:

1. `id`
2. `pvz_id`
3. `pvz_name`
4. `op_type`
5. `quantity`
6. `note`
7. `created_at`

## 3. Описание колонок

| Колонка | Тип | Описание |
| --- | --- | --- |
| `id` | UUID | Идентификатор операции. |
| `pvz_id` | UUID | Идентификатор ПВЗ, к которому относится операция. |
| `pvz_name` | string | Название ПВЗ. |
| `op_type` | string | Тип операции: `in`, `out`, `return`. |
| `quantity` | integer | Количество единиц в операции. |
| `note` | string | Примечание. Может быть пустым. |
| `created_at` | datetime | Время создания операции в UTC, формат `YYYY-MM-DDTHH:MM:SSZ`. |

## 4. Правила кодирования и экранирования

1. Файл кодируется в UTF-8.
2. Значения с запятыми, кавычками или переносами строк заключаются в двойные кавычки.
3. Внутренние кавычки экранируются удвоением: `"` → `""`.
4. Пустое значение `note` экспортируется как пустая строка в кавычках: `""`.
5. `created_at` всегда записывается в UTC.

## 5. Пример содержимого

```csv
id,pvz_id,pvz_name,op_type,quantity,note,created_at
11111111-1111-1111-1111-111111111111,22222222-2222-2222-2222-222222222222,ПВЗ №12,"in",15,"",2026-05-27T08:15:00Z
33333333-3333-3333-3333-333333333333,22222222-2222-2222-2222-222222222222,ПВЗ №12,"out",9,"Выдача заказов по маршруту №4",2026-05-27T10:05:00Z
44444444-4444-4444-4444-444444444444,55555555-5555-5555-5555-555555555555,ПВЗ №18,"return",2,"Возврат ""поврежденной"" посылки",2026-05-27T11:40:00Z
```

## 6. Примечание

В клиентском экспорте CSV для страницы загрузки используется вспомогательная функция `exportCsv`, которая добавляет BOM для корректного открытия в Excel. Серверный экспорт `operations.csv` отдает данные без BOM, но с тем же логическим порядком колонок.
