# П23. Построение DFD (Data Flow Diagram)

## 1. Внешние сущности (External Entities)
* **Оператор:** Генерирует данные о физических операциях с посылками.
* **Владелец:** Задает параметры системы и потребляет аналитическую отчетность.
* **Администратор:** Мониторит системные логи и управляет доступом.

## 2. Процессы (Processes)
* **P1: Аутентификация и Авторизация:** Проверка прав доступа через JWT.
* **P2: Управление НСИ:** Создание ПВЗ и настройка их пропускной способности.
* **P3: Регистрация операций:** Обработка событий «Приемка», «Выдача», «Возврат».
* **P4: Аналитический движок:** Расчет коэффициента загрузки в реальном времени.
* **P5: Генерация отчетов:** Формирование CSV-файлов и дашбордов.

## 3. Потоки данных (Data Flows)
1.  **Данные пользователя:** Учетные данные → [P1] → Токен доступа (обратно пользователю).
2.  **Параметры ПВЗ:** Адрес, лимит (ops/hour) → [P2] → Запись в БД.
3.  **Событие операции:** Тип, время, ID ПВЗ → [P3] → Запись в журнал операций.
4.  **Сырые данные:** Поток из журнала операций → [P4] → Результат расчета нагрузки.
5.  **Метрики:** Текущий % загрузки → [P4] → Отображение на интерфейсе (UI).
6.  **Запрос отчета:** Параметры фильтрации → [P5] → Готовый CSV-файл.

## 4. Хранилища данных (Data Stores)
* **D1: База пользователей:** Хранение хешей паролей и ролей.
* **D2: Реестр ПВЗ:** Данные о точках и их лимитах.
* **D3: Журнал операций:** История всех транзакций (Inbound/Outbound).

---

### Визуальная структура потоков (DFD Level 0)



```text
[Оператор] --(Данные операции)--> [Процесс регистрации] --(Запись)--> [[Журнал операций]]
                                        |
[[Журнал операций]] --(Поток событий)--> [Аналитический движок] --(Метрики)--> [Владелец]
                                        |
[[Реестр ПВЗ]] <--(Лимиты/Графики)-- [Процесс управления НСИ] <--(Настройки)-- [Владелец]
```
