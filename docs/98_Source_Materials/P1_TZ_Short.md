# Техническое задание, сокращенная версия

## Назначение

Создать систему, которая помогает управлять нагрузкой пунктов выдачи заказов и отображает аналитическую картину по операциям.

## Пользователи

- руководитель ПВЗ;
- администратор;
- сотрудник пункта выдачи;
- аналитик команды.

## Основные функции

- учет ПВЗ и графиков работы;
- регистрация операций `in`, `out`, `return`;
- расчет нагрузки по часам;
- выявление перегрузки;
- фильтрация и отчеты;
- экспорт данных.

## Нефункциональные требования

- понятный интерфейс;
- разделение ролей и доступов;
- предсказуемая работа расчетов;
- сохранность и целостность данных;
- возможность сопровождения и развития проекта.

## Ограничения MVP

- без сложной внешней оркестрации;
- без мобильного приложения;
- без ML-прогнозирования;
- только основные бизнес-сценарии.

## Критерии приемки

- пользователь видит данные по нагрузке;
- система корректно обрабатывает операции;
- отчеты строятся без ручной доработки;
- документация соответствует реализованным сценариям.
