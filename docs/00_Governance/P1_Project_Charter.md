# Устав проекта

**Проект:** ПВЗ Master  
**Цель:** создать информационно-аналитическую систему для контроля нагрузки пунктов выдачи заказов и поддержки управленческих решений.

## Проблема

В работе ПВЗ возникают очереди и перегрузки из-за неравномерного потока операций и отсутствия прозрачной аналитики в разрезе времени, точки и типа операции.

## Цели

- Снизить очереди и перегрузку сотрудников.
- Дать менеджерам понятную аналитику по нагрузке.
- Обеспечить контроль операций `in`, `out`, `return`.
- Сформировать основу для планирования смен и отчетности.

## Область проекта

В проект входят:

- учет ПВЗ и графиков работы;
- журнал операций;
- расчет нагрузки;
- отчеты и фильтрация;
- экспорт данных;
- базовая авторизация и роли.

В проект не входят:

- интеграции с внешними маркетплейсами в полном промышленном объеме;
- продвинутое прогнозирование на основе ML;
- мобильное приложение.

## Основные результаты

- веб-интерфейс для просмотра нагрузки;
- backend на Rust;
- схема БД и API-контракты;
- комплект проектной документации;
- MVP с аналитическими отчетами.

## Участники и роли

- Team Lead: архитектура, безопасность, управление проектом, документация.
- Backend Developer: серверная логика, БД, расчетный модуль.
- Frontend Developer: бизнес-интерфейсы, визуализация, таблицы.
- UI/UX: дизайн-система и пользовательские экраны.

## Критерии успеха

- система показывает нагрузку по часам;
- перегрузка определяется по правилу `load > 1.0`;
- ключевые сценарии пользователя реализованы;
- документация согласована с кодовой базой.
