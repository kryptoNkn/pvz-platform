# Протоколы ключевых командных встреч

Этот файл хранит сводку по ключевым встречам проекта.

## Встреча 1. Kickoff

**Тема:** запуск проекта и фиксация целей MVP  
**Решения:**

- подтверждена цель проекта как аналитической системы для ПВЗ;
- зафиксирован состав команды и зоны ответственности;
- документация делится на этапы от концепции до MVP.

**Итоги:**

- определены базовые артефакты: устав, риски, WBS, ТЗ;
- согласован подход к поэтапной поставке результата.

## Встреча 2. Аналитика требований

**Тема:** пользовательские сценарии и функциональные границы  
**Решения:**

- в MVP входят учет ПВЗ, операции и аналитика нагрузки;
- приоритет отдан сценариям просмотра и контроля загрузки;
- расширенные функции вынесены за пределы MVP.

**Итоги:**

- сформированы user stories и командные политики;
- уточнены бизнес-объекты и ключевые статусы.

## Встреча 3. Архитектура и данные

**Тема:** схема системы, БД и API  
**Решения:**

- backend строится на Rust;
- данные фиксируются в реляционной БД;
- архитектура должна поддерживать отчетность и экспорт.

**Итоги:**

- согласованы ER-диаграмма и структура БД;
- определены основные доменные сущности.

## Встреча 4. Предрелизная синхронизация

**Тема:** готовность MVP и контроль качества  
**Решения:**

- проверяется полнота документации;
- критические сценарии должны быть покрыты тестами;
- изменения в API отражаются в документах.

**Итоги:**

- зафиксированы точки контроля перед финальной сдачей;
- определен список незакрытых технических рисков.
