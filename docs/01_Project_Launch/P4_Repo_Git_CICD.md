# П4. Самостоятельная настройка репозитория с Git и CI/CD

**Ссылка:** https://gitverse.ru/kryptonkn/pvz-platform.  
**Структура веток:**
- `main` — стабильные релизы
- `develop` — интеграционная ветка
- остальные ветки добавляются для изменений, а потом мерджуются, архивируются и скрываются из проекта

**CI/CD:**
- Gitverse Actions: сборка, тесты, линт, деплой на staging.
